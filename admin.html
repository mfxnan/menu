Cara menerbitkan harga baru ke GitHub Pages / Cloudflare Pages
  1. Ubah harga langsung di tabel daftar menu atau tambah/edit menu lewat form di bawah (draft otomatis tersimpan di browser ini).
  2. Klik tombol Unduh menus.json di atas.
  3. Buka repositori GitHub kamu → masuk folder data/ → klik Add file → Upload files → unggah file menus.json lalu Commit changes.
  4. GitHub Pages / Cloudflare Pages akan otomatis memperbarui situs dalam ±30 detik.
